# Tutorials

First successful setup and end-to-end examples: follow these in order and you end with a working, governed session.

1. **Install and govern your first project** — the [README quick start](../../README.md#quick-start): install `phr-mcp`, run `phr-mcp init --packs llm,rust`, restart your agent, and confirm hooks fire.
2. **See what the hooks catch** — [Phronesis for Coding Agents](../FOR_AGENTS.md) walks through connecting Claude Code, Codex, or Gemini CLI and testing Phronesis' claims on your own repository in read-only mode.
3. **Run a long governed session** — [Phronesis for Loop-Based Agent Programming](../guides/loop-programming-guide.md) is the end-to-end example of keeping a propose/act/observe loop on the rails.

Related entry points: the [website tutorial](https://awaterma.github.io/phronesis/guide.html) and the [explainer](https://awaterma.github.io/phronesis/explainer.html) for conceptual grounding.

A dedicated first-setup tutorial beyond the README quick start is not yet written; if a setup question recurs, add one here (see [contributing/documentation.md](../contributing/documentation.md)).
