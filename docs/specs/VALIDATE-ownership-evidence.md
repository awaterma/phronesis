**Verdict policy (why no other verdicts appear).** No decision can be rated SATISFIED-BY-DESIGN: every decision's operative content (anchor selection, chain walk, name lists, normalization, relation set, docs) lives in code the inventory does not expose. The inventory's positive signals — module exists with unit tests, `clone_site [site,operation,operand]` matches D5's 3-arg form, and `lock_scope_may_cross_await` does *not* appear in the listed relations — are necessary but insufficient. No row is VIOLATED-BY-SPEC: nothing in the inventory *positively* contradicts a decision, and the extract.rs relation annotation is demonstrably non-exhaustive in format (it omits arity for `mutation_site`), so omissions are treated as conditional violations flagged in-row, not as contradictions. The spec is visible only through §5.2; downstream citations (§6.x, §7.x, §11–13) follow the decisions doc's characterization.

## Highest-Risk Unverified Assumptions

1. **Relation-set completeness.** The extract.rs annotation names only three relations; D1–D6 presuppose at least six more (a `filter` site kind per the spec's own ID example, `sync_lock_site`, `ownership_evidence`, `filter_before_clone`, `read_before_mutation`, `lock_scope_ends_before_await`). If the annotation is exhaustive rather than truncated, D2/D4/D5/D6 fail wholesale. Highest-leverage single check: dump the registered ownership relation names.
2. **Turbofish callee unwrapping.** The doc's loudest correctness point is that existing code *silently* misses `generic_function`-wrapped callees. Any of the four call-name consumers bypassing `callee_field_expression` drops sites without any error — most `collect`s are turbofish.
3. **D6 version skew.** The superseded-vs-superseding text means the code may implement the pre-2026-08-15 "unbound temporary → no scope relation" reading. The `match`/`if let` scrutinee fixtures are the discriminator between statement-boundary and innermost-expression semantics.
4. **The `lock_scope_may_cross_await` invariant.** Not only must no code path construct it; D6 *mandates* a unit test asserting never-emission. Absence of that test is itself a violation, invisible from the inventory.
5. **`await_expression` unnamed-child access.** `child_by_field_name` on it returns `None` silently — this breaks await anchors (D1), the D2 chain link, and D6 case-3 ancestor walks all at once.
6. **D7 exactness.** Using `is_whitespace` or hashing the raw text produces deterministic-but-nonconformant operand values; nothing crashes, and divergence only shows in cross-implementation comparison.
7. **No visible home for the D5 CLI-rendering clause or D8 user-facing docs.** The inventory shows only `src/` + `tests/`; both obligations could be satisfied nowhere — a violation invisible from a file list.
8. **The tree-sitter-rust 0.24 pin.** Every kind literal in the decisions doc is grammar-version-fragile; a bumped pin breaks matching silently unless fixtures pin the exact shapes.
